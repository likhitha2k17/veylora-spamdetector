# Veylora · CyberGuard AI — "Stay sharp. Stay safe."
Static, no-backend cyber awareness app (HTML/CSS/JS). All analysis runs in the browser.

## Run locally
    python3 serve.py        # then open http://localhost:8000
(Routes like /spam use absolute paths, so open via a server, not by double-clicking the files.)

## Deploy
Upload the folder as-is to Netlify, Vercel, GitHub Pages (root) or Cloudflare Pages.

## Routes
/ · /spam/ · /links/ · /number/ · /game/

Note: heuristic checks only; they can't guarantee that a message, link or number is safe.
